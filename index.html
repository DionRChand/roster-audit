Drop a casual list here

or click to browse — accepts .xlsx / .xls / .csv

How this works

Police check dates, verification officer, and remarks are entered manually below — edit any cell and it saves automatically. Uploading a simple Employee/Employee ID list here only adds casuals that aren't already on the list (with blank police check fields to fill in) — it never overwrites an existing person's data. Expired Date, Days Remaining, and Status are calculated automatically from the Received Date (received date + 3 years). Ticking Approved by Client overrides the calculated status — the casual is treated as cleared and is excluded from the Expired / Not Provided counts and filters.

Drop a weekly paysheet here

or click to browse — accepts the PAY SHEET REPORT .xlsx export

Confirm this week

How this works

Each week, drop in the full PAY SHEET REPORT export — only rows for Goodman Fielder Footscray are picked out automatically, and hours are summed per Employee ID (a casual can appear on multiple rows). You confirm the Week Ending (WE) date before it's added, so the same paysheet can never silently get logged under the wrong week. Each week's hours are added on top of the running total. Once a casual passes 152 cumulative hours, their position automatically updates from L1 to L2 (e.g. PROCESS WORKER → PROCESS WORKER L2).

Accepts the STAFF LEVEL CHECK REPORT export (for First Weekending Date Paid) or the Driscolls level 1B master file (for current positions)

How this works

Drop in the STAFF LEVEL CHECK REPORT export each week — rows for DRISCOLLS AUSTRALIA PTY LTD (excluding Tissue Culture) are picked out automatically, and each casual's First Weekending Date Paid is captured. Or drop the Driscolls level 1B master file to seed/refresh current positions. A casual becomes eligible to move from Farm Hand to Grade 1B after 3 months since their First WE date and 152 hours. Hours aren't in either report, so add or update them yourself — click any Hours cell to edit. Position is also fully editable; use the Apply button to accept the suggested promotion, or type your own.
