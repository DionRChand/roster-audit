How this works

Police check dates, verification officer, and remarks are entered manually below — edit any cell and it saves automatically. Uploading a simple Employee/Employee ID list here only adds casuals that aren't already on the list (with blank police check fields to fill in) — it never overwrites an existing person's data. Expired Date, Days Remaining, and Status are calculated automatically from the Received Date (received date + 3 years). Ticking Approved by Client overrides the calculated status — the casual is treated as cleared and is excluded from the Expired / Not Provided counts and filters.
